# PathFinder — Mini Career Roadmap Generator

A simple frontend project that generates a short career roadmap for selected paths using plain HTML, CSS and JavaScript.

## Overview

PathFinder is a small client-side app that lets a user choose a career path and then displays a list of suggested learning steps. It does not require a server — just open `index.html` in a browser.

## Files

- `index.html` — The HTML UI containing a select input for career paths and a button to generate the roadmap.
- `style.css` — Basic styling for layout and presentation.
- `script.js` — JavaScript logic that contains the `roadmapData` object (the predefined steps for each path) and the event handler that renders the selected roadmap.

## Tech

- HTML
- CSS
- JavaScript

## How to use

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Choose a career path from the dropdown and click "Generate Roadmap".

## Roadmap data

The available career paths (defined in `script.js`) are:

- Web Development
- AI / Machine Learning
- Cybersecurity

Each path maps to an ordered list of suggested learning steps (for example, Web Development includes "Learn HTML & CSS basics", "Understand JavaScript fundamentals", "Build mini projects", etc.).
